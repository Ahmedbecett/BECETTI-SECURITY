Privacy Policy — BECETTI SECURITY

Effective date: 20 November 2026 · Last updated: 23 November 2026 · Publisher: BECETTI

This policy describes exactly what the BECETTI SECURITY Windows application does with your data. It applies to the version distributed through the Microsoft Store and to the signed package distributed from this repository.

What BECETTI SECURITY does

BECETTI SECURITY is a Windows security center. It uses Microsoft Defender for scanning and threat removal. It does not replace Microsoft Defender, does not ship its own antivirus engine, and never disables Defender.

Data processed on your device

  • Security status and scan results read from Microsoft Defender.
  • Your settings, stored locally under %LocalAppData%\BecettiSecurity.
  • A local history of security events that actually occurred.
  • Cloud session tokens, protected with Windows DPAPI.

This data stays on the device. It is not transmitted unless you explicitly use a cloud feature.

Data sent to the BECETTI cloud API (only when you configure it)

  • Your account email and password. Passwords are hashed with BCrypt on the server; the plaintext is never stored.
  • SHA-256 hashes of files you explicitly choose to check. Files themselves are never uploaded.
  • Your app version, when you check for updates.

Data never collected

  • No telemetry by default. Telemetry is opt-in in Settings and off by default.
  • No browsing history, no keystrokes, no screen content, no personal files.
  • No advertising identifiers.

Third-party services

  • Microsoft Defender — on-device scanning, by Microsoft.
  • VirusTotal — server-side reputation lookups, only when the operator has configured an API key, and only file hashes are sent.
  • Microsoft Store — distribution and updates, by Microsoft.
Store builds: the Microsoft Store version is installed and updated only through the Store. It does not contact GitHub for updates and does not download executable code at runtime.

Your choices

  • Use the app fully offline: local features work without any account.
  • Sign out at any time (Cloud Security page); tokens are deleted locally.
  • Delete local data by removing %LocalAppData%\BecettiSecurity.

Children

The application is a general-purpose security tool and is not directed at children. It collects no personal information from any user beyond what is listed above.

Changes to this policy

Material changes will be reflected on this page with a new last-updated date before they take effect.
