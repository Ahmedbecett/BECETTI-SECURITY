Your complete digital protection center for Windows.

BECETTI SECURITY brings malware scanning, advanced defense, global threat
intelligence, Windows hardening, and privacy tooling into one premium dark

engine running on your machine — no fake scans, no invented results, no

Two real engines, working together
• Microsoft Defender: quick, full and custom scans, threat management and
  removal, signature updates, and real-time protection controls — all through
  Defender's official tooling (MpCmdRun and PowerShell cmdlets).
• Native YARA v4.6.0 engine (yara64): rule-based detection that runs fully
  locally, with live process memory scanning, real-time folder protection, and
  an AI-assisted YARA rule studio.

Global threat intelligence
• Live abuse.ch feeds: Feodo Tracker for C2 addresses, URLhaus for malware
  domains, MalwareBazaar for SHA-256 hashes — with an on-disk cache for
  offline work and instant IOC lookup.
• Outbound GeoIP radar: country, ASN and ISP for every connection, plus
  one-click Windows Firewall app blocking.
• MITRE ATT&CK Enterprise framework: 24 techniques automatically tagged across
  detections, with an interactive coverage matrix.

Advanced defense and hardening
• Persistence Hunter: scheduled tasks, services, Winlogon, IFEO, AppInit_DLLs.
• Ransomware protection: canary files plus real-time folder protection.
• Hosts and DNS hijack guard, with one-click remediation to Cloudflare
  1.1.1.2 or Quad9 9.9.9.9.
• File integrity monitoring (FIM) with SHA-256 baselines.
• Browser extension auditor: Chrome, Edge, Brave, Firefox.
• Camera and microphone auditing, live process DLL inspection, and an
  Emergency Center.
• One-click Windows hardening with a restore point, plus 6 real, reversible
  privacy controls.

Privacy and forensics
• Phishing and homograph URL inspector, plus Wi-Fi and ARP guard against
  network spoofing and MITM.
• Secure file shredder to DoD 5220.22-M (3 or 7 passes).
• Password breach checking through HaveIBeenPwned's k-anonymity model — your
  password is never sent.
• AES-256-GCM encrypted secure vault, and a one-click forensic evidence ZIP
  bundle.
• Software manager with Winget updates, startup manager, driver monitor, and
  USB protection.

BECETTI AI
An executive security briefing that reads your device state and summarizes it
in text and aloud, plus an "Ask BECETTI AI" button on every alert, URL,
extension, DLL and script. It answers only from verified real data — it never
invents a threat or a fix.

A global experience
• 6 languages with instant switching: English, Arabic (full right-to-left
  layout), French, Spanish, German, and Turkish.
• A 3-step first-run onboarding wizard, a Ctrl+K command palette, and an
  anti-tamper lock via Windows Hello or PIN.
• Runs as a system tray background host, with a GitHub Releases auto-updater.

Honest by design
BECETTI SECURITY uses Microsoft Defender for scanning and removal — it does not
replace it, disable it, or pretend to be a second antivirus engine. If
something cannot be verified, the app says "Unknown". If the cloud is not
configured, it says so. No simulated security, ever.

Privacy
No telemetry by default; telemetry is opt-in in Settings. No personal data is
collected without an account. Reputation checks send file hashes only — files
are never uploaded. Security state is read and displayed locally.

Requirements
Windows 10 (version 1809 or later) or Windows 11, x64. Microsoft Defender
installed (default on Windows). Internet access for cloud features, threat
intelligence and updates; local features work offline.

Developed by BECETTI.
