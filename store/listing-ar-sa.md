## 2) الوصف — Description *(مطلوب، لا يمكن تركه فارغًا)*

```
مركز الحماية الرقمية المتكامل لأجهزة Windows.

يجمع BECETTI SECURITY فحص البرمجيات الخبيثة والدفاع المتقدم وذكاء التهديدات
العالمية وتحصين النظام وأدوات الخصوصية في لوحة تحكم واحدة داكنة احترافية.
كل حالة تعرضها التطبيق مقروءة مباشرة من Windows أو من محرك يعمل على جهازك —
لا فحوصات وهمية، ولا نتائج مخترعة، ولا ادعاءات غير منفّذة.

محركان حقيقيان يعملان معًا
• Microsoft Defender: فحص سريع وكامل ومخصص، وإدارة التهديدات وإزالتها، وتحديث
  التوقيعات، والتحكم في الحماية في الوقت الحقيقي — كل ذلك عبر أدوات Defender
  الرسمية (MpCmdRun وأوامر PowerShell).
• محرك YARA الأصلي v4.6.0 (yara64): كشف بالقواعد يعمل محليًا بالكامل، مع فحص
  الذاكرة الحيّة للعمليات، وحماية المجلدات في الوقت الحقيقي، واستوديو قواعد
  YARA بمساعدة الذكاء الاصطناعي.

استخبارات التهديدات العالمية
• مصادر abuse.ch الحيّة: Feodo Tracker لعناوين C2، وURLhaus لنطاقات البرمجيات
  الخبيثة، وMalwareBazaar لبصمات SHA-256 — مع تخزين مؤقت على القرص للعمل دون
  اتصال، وبحث فوري في مؤشرات الاختراق.
• رادار GeoIP للاتصالات الصادرة: الدولة ورقم ASN ومزوّد الخدمة لكل اتصال، مع حظر
  أي تطبيق عبر جدار حماية Windows بنقرة واحدة.
• إطار MITRE ATT&CK: 24 تقنية مؤسسية تُوسم تلقائيًا على الاكتشافات، مع مصفوفة
  تغطية تفاعلية.

الدفاع المتقدم والتحصين
• صائد الاستمرارية: المهام المجدولة، والخدمات، وWinlogon، وIFEO، وAppInit_DLLs.
• حماية الفدية: ملفات الطُعم (Canary) وحماية المجلدات في الوقت الحقيقي.
• حماية ملفات hosts وDNS من الاختراق، مع تصحيح بنقرة إلى Cloudflare 1.1.1.2 أو
  Quad9 9.9.9.9.
• مراقبة سلامة الملفات (FIM) ببصمات SHA-256.
• مدقق إضافات المتصفح: Chrome وEdge وBrave وFirefox.
• تدقيق الكاميرا والميكروفون، وفاحص DLL للعمليات، ومركز الطوارئ.
• تحصين Windows بنقرة واحدة مع نقطة استعادة، و6 عناصر تحكم حقيقية بالخصوصية
  قابلة للعكس.

الخصوصية والأدوات الجنائية
• فاحص التصيّد والروابط المتشابهة (Homograph)، وحارس الواي فاي وARP ضد هجمات
  انتحال الشبكة وMITM.
• ممزّق ملفات آمن بمعيار DoD 5220.22-M (3 أو 7 مرات).
• فحص تسريب كلمات المرور عبر HaveIBeenPwned بنموذج k-Anonymity — لا تُرسل
  كلمة المرور أبدًا.
• خزنة آمنة مشفّرة بـ AES-256-GCM، وحزمة أدلة جنائية في ملف ZIP واحد.
• إدارة البرامج وتحديثات Winget، وإدارة بدء التشغيل، ومراقبة التعريفات، وحماية
  أجهزة USB.

BECETTI AI
موجز أمني تنفيذي يقرأ حالة جهازك ويلخّصها لك نصيًا وصوتيًا، وزر "اسأل BECETTI
AI" على كل تنبيه ورابط وإضافة وملف DLL ونص برمجي. يجيب فقط من معلومات حقيقية
موثّقة — لا يخترع تهديدًا ولا حلًا.

تجربة استخدام عالمية
• 6 لغات بتبديل فوري: العربية بتخطيط كامل من اليمين إلى اليسار، وEnglish،
  وFrançais، وEspañol، وDeutsch، وTürkçe.
• معالج إعداد أولي من 3 خطوات، ولوحة أوامر Ctrl+K، وقفل مضاد للعبث عبر
  Windows Hello أو رمز PIN.
• يعمل في خلفية شريط النظام، ومحدّث تلقائي عبر GitHub Releases.

صادق بالتصميم
يستخدم BECETTI SECURITY محرك Microsoft Defender للفحص والإزالة — لا يستبدله ولا
يعطّله ولا يدّعي أنه محرك مضاد فيروسات ثانٍ. إذا تعذّر التحقق من أمر ما يعرض
"غير معروف". وإذا لم تُضبط السحابة يقول ذلك صراحة. لا أمان مُحاكى أبدًا.

الخصوصية
لا قياس عن بُعد (telemetry) افتراضيًا؛ التفعيل اختياري من الإعدادات. لا تُجمع
بيانات شخصية دون حساب. فحوصات السمعة ترسل بصمات الملفات فقط — لا تُرفع الملفات
أبدًا. حالة الأمان تُقرأ وتُعرض محليًا.

المتطلبات
Windows 10 (الإصدار 1809 أو أحدث) أو Windows 11، بمعمارية x64. Microsoft
Defender مثبّت (افتراضي في Windows). اتصال بالإنترنت لميزات السحابة وذكاء
التهديدات والتحديثات؛ وتعمل الميزات المحلية دون اتصال.
```
