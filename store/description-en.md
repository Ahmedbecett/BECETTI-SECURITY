# BECETTI SECURITY

Your Digital Protection Center.

BECETTI SECURITY brings your Windows security into one premium, dark,
cybersecurity-grade dashboard — powered by Microsoft Defender and the BECETTI
cloud API. No fake scans. No invented results. Every status you see is read
live from Windows.

## What you get
- **Dashboard** — verified antivirus, real-time protection, firewall,
  security-intelligence and device status, read live from Windows.
- **Smart Scan** — Quick, Full and Custom file/folder scans through
  Microsoft Defender, with real detection reporting.
- **Real-Time Protection** — verified Defender state, signature updates,
  and elevation-aware controls.
- **Cloud Security** — optional BECETTI cloud connection for file-reputation
  checks (hashes only — files are never uploaded) and update information.
- **Threat Management** — real Defender detections with verified removal.
- **Privacy & Network** — measured network, TLS and configuration checks
  with honest recommendations.
- **Security History** — a local log of real security events.
- **Updates** — app updates and Defender signature updates, kept separate.
- **English and Arabic** with full right-to-left layout.

## Honest by design
BECETTI SECURITY uses Microsoft Defender for scanning — it does not replace
it, disable it, or pretend to be a second antivirus engine. If something
cannot be verified, the app says "Unknown". If the cloud is not configured,
it says so. No simulated security, ever.

## Requirements
Windows 10 (version 1809+) or Windows 11, Microsoft Defender installed
(default on Windows), internet access for cloud features and signature
updates.
