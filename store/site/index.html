What BECETTI SECURITY does

BECETTI SECURITY is a Windows security center that uses Microsoft Defender for scanning and threat removal. It does not replace Microsoft Defender.

Data processed on your device

  • Security status and scan results read from Microsoft Defender.
  • Your settings, stored locally under %LocalAppData%\BecettiSecurity.
  • A local history of security events that actually occurred.
  • Cloud session tokens, protected with Windows DPAPI.

Data sent to the BECETTI cloud API (only when you configure it)

  • Your account email and password (passwords are hashed with BCrypt on the server; plaintext is never stored).
  • SHA-256 hashes of files you explicitly choose to check. Files themselves are never uploaded.
  • Your app version, when you check for updates.

Data never collected

  • No telemetry by default. Telemetry is opt-in in Settings and off by default.
  • No browsing history, no keystrokes, no screen content, no personal files.
  • No advertising identifiers.

Third-party services

  • Microsoft Defender (on-device, by Microsoft).
  • VirusTotal (server-side reputation lookups, only when the operator has configured an API key; hashes only).
  • Microsoft Store (distribution and updates, by Microsoft).

Your choices

  • Use the app fully offline: local features work without any account.
  • Sign out at any time (Cloud Security page); tokens are deleted locally.
  • Delete local data by removing %LocalAppData%\BecettiSecurity.

ما الذي يقوم به BECETTI SECURITY

BECETTI SECURITY هو مركز أمان لنظام Windows يستخدم Microsoft Defender للفحص وإزالة التهديدات. لا يستبدل Microsoft Defender.

البيانات المعالجة على جهازك

  • حالة الأمان ونتائج الفحص المقروءة من Microsoft Defender.
  • إعداداتك، مخزّنة محليًا تحت %LocalAppData%\BecettiSecurity.
  • سجل محلي للأحداث الأمنية التي وقعت فعليًا.
  • رموز جلسة السحابة، محمية باستخدام Windows DPAPI.

البيانات المُرسلة إلى واجهة BECETTI السحابية (فقط عند تهيئتها)

  • بريدك الإلكتروني وكلمة المرور (كلمات المرور مُجزّأة بـ BCrypt على الخادم؛ لا يُخزَّن النص الصريح أبدًا).
  • بصمات SHA-256 للملفات التي تختار فحصها صراحةً. لا تُرفع الملفات نفسها أبدًا.
  • إصدار التطبيق، عند التحقق من التحديثات.

بيانات لا تُجمع أبدًا

  • لا قياس عن بُعد افتراضيًا. القياس عن بُعد اختياري في الإعدادات ومُعطّل افتراضيًا.
  • لا سجل تصفح، لا ضغطات مفاتيح، لا محتوى شاشة، لا ملفات شخصية.
  • لا معرّفات إعلانية.

خدمات الطرف الثالث

  • Microsoft Defender (على الجهاز، من Microsoft).
  • VirusTotal (فحوصات سمعة من جانب الخادم، فقط عند تهيئة مفتاح API من قبل المشغّل؛ بصمات فقط).
  • Microsoft Store (التوزيع والتحديثات، من Microsoft).

خياراتك

  • استخدم التطبيق دون اتصال بالكامل: الميزات المحلية تعمل بدون أي حساب.
  • سجّل الخروج في أي وقت (صفحة أمن السحابة)؛ تُحذف الرموز محليًا.
  • احذف البيانات المحلية بإزالة %LocalAppData%\BecettiSecurity.
