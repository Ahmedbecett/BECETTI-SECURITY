# BECETTI SECURITY

مركز الحماية الرقمية الخاص بك.

يجمع BECETTI SECURITY أمان Windows في لوحة تحكم واحدة فاخرة بتصميم
داكن احترافي للأمن السيبراني — مدعومًا بـ Microsoft Defender وواجهة
BECETTI السحابية. لا فحوصات وهمية. لا نتائج مخترعة. كل حالة تراها
مقروءة مباشرة من Windows.

## ما ستحصل عليه
- **لوحة التحكم** — حالة موثقة لمضاد الفيروسات والحماية في الوقت
  الحقيقي والجدار الناري ومعلومات الأمان والجهاز، مقروءة مباشرة.
- **فحص ذكي** — فحص سريع وكامل ومخصص للملفات والمجلدات عبر
  Microsoft Defender مع تقارير اكتشاف حقيقية.
- **الحماية في الوقت الحقيقي** — حالة Defender موثقة وتحديثات
  التوقيعات وأدوات تحكم واعية بالصلاحيات.
- **أمن السحابة** — اتصال سحابي اختياري من BECETTI لفحص سمعة الملفات
  (البصمات فقط — لا تُرفع الملفات أبدًا) ومعلومات التحديث.
- **إدارة التهديدات** — اكتشافات Defender الحقيقية مع إزالة موثقة.
- **الخصوصية والشبكة** — فحوصات شبكة وTLS وإعدادات مقاسة مع توصيات
  صادقة.
- **سجل الأمان** — سجل محلي للأحداث الأمنية الحقيقية.
- **التحديثات** — تحديثات التطبيق وتحديثات توقيعات Defender منفصلة.
- **الإنجليزية والعربية** مع تخطيط كامل من اليمين إلى اليسار.

## صادق بالتصميم
يستخدم BECETTI SECURITY برنامج Microsoft Defender للفحص — لا يستبدله
ولا يعطّله ولا يدّعي أنه محرك مضاد فيروسات ثانٍ. إذا تعذر التحقق من
شيء ما، يعرض التطبيق "غير معروف". وإذا لم تُهيأ السحابة، يقول ذلك
صراحة. لا أمان محاكى أبدًا.

## المتطلبات
Windows 10 (الإصدار 1809 أو أحدث) أو Windows 11، مع تثبيت
Microsoft Defender (افتراضي في Windows)، واتصال بالإنترنت لميزات
السحابة وتحديثات التوقيعات.

تم التطوير بواسطة BECETTI.
