What the SDK processes
----------------------
  Per the MG Ads SDK privacy disclosure: information the user actively
  uploads, device information (device model, operating-system version),
  network information (network type), application information and interface
  information. Purpose: advertising and cross-promotion. Data is transmitted
  over HTTPS with de-identification measures applied by the provider.

  See store/privacy-policy.md, section "Advertising (MG Ads)", for the
  user-facing disclosure. Users can disable all ads in Settings ->
  Advertising -> "Show ads".

WebView2 Runtime
----------------
  The SDK uses Microsoft Edge WebView2 for image/web/video creatives.
  Windows 11 includes the Evergreen WebView2 Runtime. On Windows 10 devices
  where it is missing, ads simply do not render; the security features of
  BECETTI SECURITY are unaffected. The host sets WEBVIEW2_USER_DATA_FOLDER to
  %LocalAppData%\BecettiSecurity\WebView2 because the MSIX install folder is
  read-only.
